# LEARN ไม่นิ่ง: ภารกิจพิชิตพาราโบลา

เกมแบบทดสอบพาราโบลา 7 ด่าน สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 3

## การเผยแพร่ผ่าน GitHub Pages

1. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ไปที่รากของ Repository `learn-parabola-game`
2. ไปที่ **Settings → Pages**
3. ตั้งค่า **Source** เป็น **GitHub Actions**
4. เปิดแท็บ **Actions** และรอให้ `Deploy Next.js to GitHub Pages` สำเร็จ
5. เกมจะอยู่ที่ `https://skk5608070-svg.github.io/learn-parabola-game/`

คะแนนในรุ่นนี้บันทึกในเบราว์เซอร์ของอุปกรณ์ด้วย localStorage ยังไม่ได้ส่งเข้า Google Sheets
